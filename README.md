# Image Classifier
This is an image classifier I made from scratch in C++ using no artificial intelligence libraries. While not very efficient I had a lot of fun learning the basics of how algorithms like image convolution, ReLU and max pooling work and have implemented them in this project using nothing more that for loops. I was originally inspired to work on this after reading [this article](https://developers.google.com/machine-learning/practica/image-classification/convolutional-neural-networks) from a Google course (which has unfortunately been taken down but is still available on the Internet Archive). After finding out about how simplistic machine learning models simply use linear regression I was interested in how that could be applied to something more complex like image classification as it seemed unrealistic that plotting pixel information would work and I've found it fascinating finding out about all the algorithms used to turn this pixel information into identifiable features that can be fed into a neural network. I originally started this as a Python Flask website but when I found myself having to do all sorts of efficiency improvements to get barely usable speeds I gave up a little before getting to back-propagation. I came back to it a year later after having learned C++ and remade it as a Qt application which is much faster and has allowed me to write the algorithms in a simple way that doesn't require complex efficiency improvements that utilise the GPU or use tons of memory.
